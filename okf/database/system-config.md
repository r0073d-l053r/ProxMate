# Purpose

A flat key/value table holding every setting ProxMate configures at runtime (setup wizard, admin settings), as opposed to process env (see [backend environment](/env/backend-environment.md)). All access goes through `getConfig` / `setConfig` in `config.service.ts`.[^svc] The individual keys are documented by group:

- [Proxmox connection](/config/proxmox-connection.md)
- [Provisioning defaults](/config/provisioning-defaults.md)
- [Tenant isolation](/config/tenant-isolation.md)
- [SSO](/config/sso.md)
- [SMTP](/config/smtp.md)
- [Notifications](/config/notifications.md)
- [IDE](/config/ide.md)
- [Cluster balancer](/config/cluster-balancer.md)
- [Cloud-init](/config/cloud-init.md)
- [App-DB backup](/config/appdb-backup.md)
- [Template refresh](/config/template-refresh.md)
- [Platform secrets](/config/platform-secrets.md)

# Relationships

None. Rows are looked up by key only.[^schema]

# Invariants

- `getConfig(key)` returns null for a missing row and decrypts transparently when `sensitive`.[^svc]
- `setConfig(key, value, sensitive = false)` is an upsert that rewrites **both** `value` and `sensitive`.[^svc]
- `isSetupComplete()` is `value === 'true'` for key `setup_complete`, and returns false on any DB error.[^svc]
- Keys written as sensitive in code: `jwt_secret` (64 random bytes hex, generated by setup), `proxmox_token_secret`, `smtp_pass`, `sso_client_secret`, `ide_gateway_key`, `kiosk_exit_pin` (stored as a bcrypt hash, then encrypted), and `notify_webhook_url` (sensitive only when non-empty).[^setup] [^kiosk] [^notify]

# Gotchas

- Writing a secret key through `setConfig` without `sensitive = true` silently stores it in plaintext and clears the flag.[^svc]
- Losing or changing `ENCRYPTION_KEY` makes every sensitive row (including `jwt_secret`) undecryptable. `getConfig` then throws instead of returning null.[^crypto]
- The service has no delete. Settings are "cleared" by overwriting the value.[^svc]
- Rotating `jwt_secret` invalidates every outstanding session JWT (see [Session](/database/session.md)).[^setup]
