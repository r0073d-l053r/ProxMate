# Playbooks

Step-by-step procedures for operators and maintainers.

# Playbook

* [Maintaining this OKF bundle](maintaining-this-bundle.md) - How to keep the okf/ knowledge bundle conformant and in sync when the ProxMate code changes.
* [Setting up ProxMate on an SDN-only cluster](sdn-only-cluster.md) - Steps to pick an SDN VNet as the default network when the cluster has no Linux bridge for guests.
* [Settling unconfirmed machines](unconfirmed-machines.md) - How an admin adopts or removes machines whose Proxmox guest does not carry their ProxMate ownership tag, so they can be used or deleted again.
* [Upgrading from ProxMate 1.0.x to 1.1](upgrading-from-1-0.md) - Steps for an operator moving a 1.0.x install to 1.1.0 - compose override, updater units, token privileges, and what to check after the first start.
